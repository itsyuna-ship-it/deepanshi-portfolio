# Deepanshi Guha — Academic + Creative Portfolio

A responsive, single-page student portfolio designed for GitHub Pages.

## What is included

- `index.html` — all website text and page sections
- `styles.css` — colours, typography, layout and mobile design
- `script.js` — menu, scroll progress and reveal animations
- `favicon.svg` — DG browser-tab icon
- `site.webmanifest` — website identity information
- `robots.txt` and `sitemap.xml` — search-engine support
- `assets/` — reserved for Deepanshi's future anime portrait

No photograph, email address or other private contact information is included
in this version.

The interactive version includes a full-screen editorial menu, working section
navigation, expandable project stories, achievement accordions, contextual
“coming soon” messages, active navigation feedback and a back-to-top control.

Performance and accessibility are built in: later sections render
progressively, reduced motion/transparency preferences are respected, and
keyboard visitors can skip straight to the content or navigate the full-screen
menu safely.

## Preview on your computer

1. Unzip the package.
2. Open the extracted folder.
3. Double-click `index.html`.

The page will open in your browser. The full portfolio works without internet
access; only the live headline refresh requires a connection.

## Upload to GitHub

1. Sign in to GitHub.
2. Create a new **public** repository, such as `deepanshi-portfolio`.
3. Initialise it with a README if GitHub asks.
4. Select **Add file → Upload files**.
5. Open this extracted package and select everything *inside* the
   `deepanshi-portfolio` folder.
6. Upload the files and commit the changes.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**.
9. Choose `main`, select `/ (root)`, and save.
10. Wait a few minutes for GitHub to display the published website address.

Upload the contents of the folder—not the ZIP file itself and not an additional
outer folder—so that `index.html` sits at the top level of the repository.

## Custom domain

First confirm that the GitHub Pages address works correctly. After that,
connect `deepanshiguha.com` through GitHub Pages and update the DNS records at
the domain registrar. Do not create a `CNAME` file until the domain-connection
step is ready.

## Updating the website later

- Edit wording and achievements in `index.html`.
- Change colours near the top of `styles.css`.
- Add the future anime portrait inside `assets/`.
- Keep file names lowercase and avoid spaces.

The website is intentionally structured so future research papers,
certifications, projects, performances and contact links can be added without
redesigning the entire site.
